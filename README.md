# 🚀 QRCraft Pro — Ultimate QR Code Studio

QRCraft Pro is a powerful, sleek, and feature-rich Web Application built with Python (Flask) that allows users to generate customizable, branded QR codes in seconds.

## ✨ Features
- ⚡ **Preset Style Themes:** Choose from Instagram Pink, WhatsApp Green, Cyberpunk Neon, or Classic B&W styles.
- 🎯 **Center Logo Integration:** Overlay your own brand logo or icon on the QR code with high error correction.
- 📶 **Wi-Fi & Photo Direct Support:** Generate Wi-Fi credentials or instant photo-link QR codes.
- 🖼️ **Multi-Format Downloads:** Export high-resolution PNGs or print-ready PDFs.
- 🛡️ **Rate Limiting & Protection:** Built-in IP-based rate limiting (`Flask-Limiter`) to prevent server abuse and spamming.
- 📱 **Mobile Responsive:** Works seamlessly on smartphones, tablets, and desktops.

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **QR Generation:** `qrcode`, `Pillow`
- **Frontend:** HTML5, CSS3, JavaScript (jsPDF)
- **Deployment:** Render / Gunicorn
