What is a QR code?

A QR code is a machine-readable pattern that stores information. When scanned, it can open a website, display text or trigger another supported action.

How to make one

Paste the correct destination, generate the code, download the PNG and test it with your phone camera before printing or publishing it.

Make it scannable

Keep strong contrast, leave clear space around the code and avoid covering its corners. Always test the final image at the size where people will scan it.

Security first

QRCraft accepts only HTTP/HTTPS links for website QR generation. Authentication uses hashed passwords, rate limits and secure session cookies.

Payments

QRCraft creates the order on the server and verifies the Razorpay signature before adding credits. A client-side “success” message alone can never grant credits.
