About QRCraft

QRCraft is a free QR code generator built for quick, everyday QR creation. It lets you turn common information into a scannable QR code directly from your browser, with no account or payment required.

For normal QR modes, the information is prepared in your browser. Photo QR codes are different because the image needs a temporary online URL so another device can open it after scanning.

What is a QR code?

A QR code is a two-dimensional barcode that can store information such as a website address, plain text, contact details, Wi-Fi settings, an email action or a location. A phone camera or QR scanner can read the code and open or display the stored information.

How to create a QR code with QRCraft

  1. Choose a QR type such as Link, Text, Wi-Fi, Contact, Email, Phone, WhatsApp or Location.
  2. Enter the information you want to share.
  3. Choose the QR size, error correction and colors if needed.
  4. Select Generate QR Code and check the preview.
  5. Download, copy or share the generated QR information.

QR code types available

  • Link: create a QR code for a website or web page.
  • Text: share a note, message or other plain text.
  • Photo: create a QR code that opens a temporarily hosted image.
  • Wi-Fi: encode a network name, password and security type.
  • Contact: share basic contact information in vCard format.
  • Email: prepare an email address with an optional subject and message.
  • Phone: create a QR code containing a phone action.
  • WhatsApp: open a WhatsApp chat link with an optional message.
  • Location: encode latitude and longitude as a map location.

Tips for making a QR code easy to scan

  • Use strong contrast between the QR pattern and its background.
  • Keep the QR code large enough for the distance at which it will be scanned.
  • Test the final downloaded or printed code with a phone before sharing it widely.
  • For important links, check that the destination still works before publishing the QR code.
